# Aniimo Friendship Guide

Fan-made reference for Aniimo's friend Affinity system and Illusory Friends / Illusory Aniimo, compiled from the game's client data files.

Live page: https://sargeeva.github.io/aniimo-friendship-guide/

- `index.html` — the guide (self-contained, images embedded)
- `assets/` — full-resolution UI images extracted from the game

Companion site: [Aniimo Egg Heist Loot Tables](https://sargeeva.github.io/aniimo-egg-heist-loot/)
